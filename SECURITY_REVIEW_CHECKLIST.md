# Security Review Checklist

- [ ] Passport identity is signed/verified.
- [ ] Capabilities are explicitly authorized.
- [ ] Delegation is scoped and replay-aware.
- [ ] Dangerous tools are denied or sandboxed.
- [ ] Requests are rate-limited.
- [ ] Secrets are redacted from audit output.
- [ ] Evidence is cryptographically verifiable.
- [ ] Registry retrieval is verification-aware.
- [ ] Red-team tests pass.
- [ ] Known limitations are documented.
- [ ] No claim of "unhackable" security is made.
