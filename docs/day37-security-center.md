# Day 37 — Security Center

## Reviewer view

The recommended dashboard card order is:

- Passport trust
- Identity/signature
- Capability authorization
- Delegation status
- Tool sandbox
- Replay/rate-limit status
- Evidence integrity
- Registry status
- Red-team result
- Known limitations

Every status should link to an actual local report/test where available.

## Security language

Use "verified by local tests" or "local evidence" rather than "secure" or
"unhackable". The dashboard is not an authentication boundary.
