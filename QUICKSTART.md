# Agent Passport — Quick Start

## 1. Install

```bash
python -m pip install -e .
```

## 2. Run the local showcase

```bash
python examples/final_release_check.py
```

## 3. Run tests

```bash
python -m pytest -q
```

## 4. Security

Do not place API keys, private keys, passwords, or production credentials in the repository.
Use environment variables or a dedicated secret manager.

For the challenge submission, use the repository root containing `agent.yaml`.
